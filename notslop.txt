VagrantManager.py manages the variables for VM creation:
    - It assumes that a folder is provided with all of the CSVs containing all of the employees and roles
    - The name of the files are password_info_{boxNum}.csv for each box created 
    - The columns of the CSV read are employee_ id,role, and password_hash
    - The script writes the vars.yaml file read by the Vagrantfile to create the machines
    - The # of files in the directory = the # of boxes created
    - The # of rows in the csv = the # of users created (all machines have the same # of users for now)

Start the API and tracker from the repository root with:

python vagrant/authRecorder.py --host 0.0.0.0 --port 8001 --sleep-time 30

0.0.0.0 listens on all network interfaces. Clients should connect to this
machine's network address, and the host firewall must allow the selected port.
The tracker uses `vagrant/generated_files/vars.yaml` and the default
`users/usersInfo.csv`.

The polling route is `GET /employees/newest`---
